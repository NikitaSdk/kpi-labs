# IoT and Embedded Systems (STM32)

STM32F103C6 firmware in C, simulated in Proteus.

| Lab | Topic | Code |
| --- | --- | --- |
| [lab-1-gpio-interrupts-adc](lab-1-gpio-interrupts-adc) | GPIO output and input, button interrupts (EXTI), ADC-driven LED blinking | see report |
| [lab-2-timers-pwm-dma](lab-2-timers-pwm-dma) | SysTick, basic timers, PWM generation and period capture, DMA, averaged ADC | in folder |
| [lab-3-pi-controller-dac-adc](lab-3-pi-controller-dac-adc) | Proportional and PI controller for a voltage / current converter on DAC + ADC | see report |
| [lab-4-uart-i2c-spi](lab-4-uart-i2c-spi) | Data exchange between 2–3 MCUs over UART (full / half duplex), I2C, SPI | in folder |
| [lab-5-freertos](lab-5-freertos) | FreeRTOS tasks, priorities and the scheduler | in folder |

Each lab folder has `report.pdf` (in Ukrainian).
