# University Labs (KPI)

All my lab works from 5 years of Computer Science at **Igor Sikorsky Kyiv Polytechnic Institute** (2021–2026), grouped by skill.
Inside every course folder: the code and, for most labs, the report (`report.pdf`, in Ukrainian).

| Skill area | What I did there |
| --- | --- |
| [AI and Machine Learning](1-ai-and-machine-learning) | Neural networks, LLM agents, medical imaging, Big Data, classic ML |
| [Backend, Web and Databases](2-backend-web-and-databases) | Microservices, distributed databases, cloud, SQL / NoSQL, React, software design |
| [C++ and Systems Programming](3-cpp-and-systems-programming) | Operating systems, threads, sockets, parallel computing |
| [Embedded, IoT and Hardware](4-embedded-iot-and-hardware) | STM32 firmware, FreeRTOS, control systems, signal processing |
| [Java](5-java) | OOP labs and a coursework with three databases |
| [Algorithms, Math and Security](6-algorithms-math-and-security) | Coding theory, optimization, cryptography, numerical methods |
| [Mini Projects](7-mini-projects) | Small personal apps |
